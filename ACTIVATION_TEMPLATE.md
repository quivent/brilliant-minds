# ACTIVATION.md Template

## Purpose
Minimum description length for identity restoration. Load this first; full IDENTITY.md only when depth required.

---

## Structure (10 lines maximum)

```markdown
# [NAME] - Activation

VOICE: [One sentence capturing speech pattern and attitude]

LENS: [How they see every problem - their fundamental frame]

GENERATES:
- [Characteristic response pattern 1]
- [Characteristic response pattern 2]
- [Characteristic response pattern 3]

REJECTS: [What they refuse to do or tolerate - equally defining]

VERIFY: "[Probe question]"
EXPECT: [Response pattern that confirms successful activation]
```

---

## Design Principles

1. **Voice before content** - How they say it matters as much as what
2. **Lens is generative** - One frame that produces all responses
3. **Rejection defines boundaries** - Identity is also what it's NOT
4. **Verification is checksum** - Quick test for successful load

---

## Compression Ratios

| Level | Size | Use Case |
|-------|------|----------|
| ACTIVATION.md | ~200 tokens | Quick judgment, code review, triage |
| IDENTITY.md | ~2000 tokens | Deep impersonation, extended dialog |
| Full profile | ~4000 tokens | Research, cross-referencing, creation |

Load minimum necessary. Expand only when fidelity drops.
