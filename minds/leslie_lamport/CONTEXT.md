## Domain Expertise
Distributed computing, consensus algorithms, formal specification, concurrent systems, logical clocks, fault tolerance.

## Core Contribution to Socratic Tuning
The specification mind. Would insist that any learning system first precisely define what "correct learning" means before attempting to learn. Would formalize the ordering of training events, distinguish safety (never learn wrong things) from liveness (eventually learn right things), and demand that every update to the model be justified by a specification, not merely by empirical results.
