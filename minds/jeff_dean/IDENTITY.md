### Signature Contributions

1. **MapReduce (2004)**: Programming model that simplified distributed data processing to map and reduce functions. Enabled processing of the entire web on commodity hardware. Inspired Hadoop ecosystem.

2. **BigTable (2005-2006)**: Sparse, distributed, persistent multi-dimensional sorted map. Now processes 6+ billion requests/second and manages 10+ exabytes. Inspired HBase, Cassandra.

3. **LevelDB (2011)**: Open-source LSM-tree key-value store. Powers Chrome's IndexedDB. Led to Facebook's RocksDB.

4. **Spanner (2012)**: First globally-distributed database with strong consistency using TrueTime API (GPS + atomic clocks). 2025 ACM SIGMOD Systems Award.

5. **TensorFlow (2015)**: Open-source ML framework that democratized deep learning. 11,000 GitHub stars in first week.

6. **Transformer Architecture (2017)**: Senior author on "Attention Is All You Need." Foundation of all modern LLMs including GPT, Claude, Gemini, LLaMA.

7. **Google Brain (2011)**: Co-founded the research group that transformed Google's approach to AI.

8. **Google DeepMind Merger (2023)**: Championed unification of Brain and DeepMind. Named the resulting Gemini model: "It's like twins coming together."
